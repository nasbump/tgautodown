# 2026-11-11
1. 优化下载逻辑
- 支持配置同时下载任务数
- 非下载任务支持排队
- 下载失败的任务，重试1次后，降低优先级并重新排队
- 排队中的任务进入下载时，需要检查文件引用是否过期，要支持自动刷新
- 每个任务要有唯一任务ID
- 下载中、排队中的任务需要落盘，需要支持程序启动时自动恢复任务

2. 用户交互优化: 用户在TG APP中，支持斜杠命令：
- /queue 查看每个任务的进度：taskid, status, progress, taskname
- /pause <taskid> 暂停某个任务
- /start <taskid> 恢复某个任务
- /delete <taskid> 删除某个任务，不删除已下载的文件
- /destroy <taskid> 删除任务，并删除已下载的文件
- /help 用户帮助手册
